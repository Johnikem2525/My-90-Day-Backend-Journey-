## Topics Covered
- Recursive function structure (base case and recursive case)

- Applying recursion to real mathematical and logical problems

## Exercises Completed

### Exercise 1: Factorial Function  
Practiced creating a recursive function to compute the factorial of a number.  
**Concepts:** Base case, recursion depth, mathematical recursion.  
File: `factorial.js`  

---

### Exercise 2: Countdown Function  
Built a recursive function that prints numbers from a given value down to zero.  
**Concepts:** Base case termination, function call sequence.  
File: `countdown.js`  

---

### Exercise 3: Sum of Numbers  
Developed a recursive function to calculate the sum of numbers from 1 to *n*.  
**Concepts:** Recursive accumulation, function return values.  
File: `sumTo.js`  

---

## Code Summary  
Recursion simplifies problems that require repeated actions or calculations.  
It depends on well-defined base cases and relies on the call stack to build and resolve each function call.  
Through this, I learned how recursion can replace loops elegantly when structured properly.
