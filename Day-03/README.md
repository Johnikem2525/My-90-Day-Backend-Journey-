# Exercises

1. Even Numbers (0–12)

File: EvenNum.js

Goal: Output all even numbers from 0 to 12.

The while loop keeps running as long as the condition (number <= 12) is true.
We start from 0, print it, then increase by 2 each time, producing even numbers up to 12.

2. Power of Two

File: PowerOfTwo.js

Goal: To calculate and display 2^10 (2 to the power of 10).

Here I used two bindings:

result to store my ongoing multiplication.

counter to track how many times I’ve multiplied by 2.
When counter reaches 10, the loop stops.

Output: 2 to the power of 10 is: 1024

3. User Input Prompt

File: UserPromptLoop.js

Goal: Keep asking for the user’s name until a valid name is entered.

Explanation:

The do...while loop runs at least once before checking the condition.

If the user presses enter without typing anything, the loop repeats until a name is given.
