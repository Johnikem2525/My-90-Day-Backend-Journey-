## Exercises Completed  

### Exercise 1 – Looping a Triangle  
Created a loop that prints a growing triangle of “#” symbols using string concatenation.  
**Concepts:** Loop iteration, string length tracking, incremental output.  
*File: triangle.js*  

---

### Exercise 2 – FizzBuzz  
Printed numbers from 1 to 100, replacing multiples of 3 and 5 with “Fizz”, “Buzz”, or “FizzBuzz”.  
**Concepts:** Modular arithmetic, multiple conditional statements, clean code logic.  
*File: Fizzbuzz.js*  

---

### Exercise 3 – Chessboard Pattern  
Generated an 8×8 grid representing a chessboard with alternating spaces and “#”.  
**Concepts:** Nested loops, conditionals, dynamic grid generation using variables.  

*File: chessboard.js*
