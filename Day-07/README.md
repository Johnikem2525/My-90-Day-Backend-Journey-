# Day 7: Functions as Values and Bindings

**Date:** October 12, 2025  

**Focus:** Understanding that functions are treated as values and can be stored, passed, or reassigned.  

---

## Topics Covered  

- Difference between function names and function values  
- Functions as first-class values  
- Passing functions as arguments  
- Reassigning function bindings  

---

## Exercises Completed  

### Exercise 1: Function as a Value  
Created a `sayHi()` function and stored it in another variable `greet`.  
Called `greet()` successfully to show that functions can be treated like values.  
File: `sayHi.js`  

### Exercise 2: Passing Function as Argument  
Built a higher-order function `runTwice(func)` to call any function twice.  
Tested it with the `sayHi()` function.  
File: `runTwice.js`  

### Exercise 3: Reassigning Function Binding  
Implemented `startEngine` and changed its behavior based on a `safeMode` condition.  
Demonstrated how function bindings can be reassigned.  
File: `startEngine.js`  

---

## Code Summary  

- Functions in JavaScript can act like normal values.  
- You can assign them to new variables or pass them around.  
- Function bindings can be replaced to modify behavior dynamically.
