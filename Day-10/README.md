# Day 10: Optional Arguments and Closures

**Date:** October 15, 2025  
**Focus:** Understanding how JavaScript functions handle missing parameters (optional arguments) and how closures allow inner functions to retain access to outer variables.

---

### Topics Covered
- Optional arguments and default parameter values  
- Closures and variable scope retention  
- Higher-order functions that return other functions  
- Combining closures with optional parameters for flexibility  

---

### Exercises Completed

#### Exercise 1 – Optional Minus Function
Created a function using optional arguments that behaves like the minus operator.  
If only one parameter is passed, it returns the negative of that number; if both are passed, it returns their difference.  
**Concepts:** Optional arguments, parameter checking, default handling.  File: `minus.js`  

---

#### Exercise 2: wrapValue() Closure Example
Built a function that “wraps” a value and returns another function that accesses it even after the original one has finished running.  
This demonstrated how closures preserve variables from their outer scope.  
**Concepts:** Closures, scope, data encapsulation.  
File: `remValue.js`  

---

#### Exercise 3: Multiplier with Closure and Optional Parameter
Created a higher-order function that returns another function.  
Added a default parameter to show how closures and optional arguments can work together.  
**Concepts:** Closures, optional parameters, higher-order functions.  
File: `multiplier.js`  

---

### Code Summary
Today’s study showed how flexible and powerful JavaScript functions can be.  
Closures helped me understand how inner functions “remember” outer variables even after execution,  
and default parameters made functions more dynamic and reusable.
